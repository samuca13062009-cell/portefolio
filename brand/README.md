# Sinal: Samuel Camargo's identity

An S drawn in one stroke: the top half is round (analog, sound) and the bottom half is square (digital, code). The round top is also a C, so both initials sit in the symbol. The wordmark is drawn with the same rule (round above the middle, square below it) and is not a font.

Everything is generated by `node tools/make-brand.js --png` (SVG only without `--png`). Geometry and colours live in that script and are copied to `geometry.json`.

## Files

| Use | SVG (`svg/`) | PNG (`png/`) |
|---|---|---|
| Primary, dark ground | `logo-horizontal-dark.svg` | `logo-horizontal-dark.png` (3200 px wide) |
| Primary, light ground | `logo-horizontal-light.svg` | `logo-horizontal-light.png` |
| Transparent, for dark / light grounds | `logo-horizontal-on-dark-transparent.svg`, `logo-horizontal-on-light-transparent.svg` | same names |
| Black / white | `logo-horizontal-black.svg`, `logo-horizontal-white.svg` | same names |
| Stacked | `logo-stacked-dark.svg`, `-black`, `-white` | same names (2400 px) |
| Symbol | `symbol-dark.svg`, `-cyan`, `-midnight`, `-black`, `-white` | same names (2048 px) |
| Wordmark | `wordmark-black.svg`, `-white`, `-ink` | same names |
| Favicon | `favicon.svg` (heavier cut for small sizes) | `favicon-16/32/48/180/192/512.png`, `favicon.ico` |

All files except `-dark`, `-light` and `favicon` have transparent backgrounds.

## Colours (from the portfolio's "build #21" redesign)

- Midnight `#0A1030`: home ground
- Signal cyan `#2EE6FF`: symbol on dark
- Moon ink `#E7ECF5`: wordmark on dark
- Cyan, light mode `#006C8F` and ink `#12162E`: symbol and wordmark on light grounds

## Rules

- Never add gradients, shadows or outlines. The logo is one flat colour per part.
- Minimum size: symbol 16 px (use `favicon.svg` below 32 px); horizontal logo 120 px wide.
- Clear space: the height of the wordmark's x-height on every side.
- Don't redraw the wordmark in a font, stretch it, or rotate the symbol.
